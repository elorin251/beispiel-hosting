Grundlegende Struktur

<!DOCTYPE html>

Dokumententyp angeben, MUSS am Anfang der HTML-Datei definiert werden

<html lang="de">

root-Tag, kennzeichnet Text innerhalb vom Container als HTML-Dokument

<head>

Enthält die Metainformationen und den Titel des Dokuments, alles das nicht sichtbar ist

<body>

Enthält alle Inhalte, die auf der Seite dargestellt werden

Inhalte in <head>

<title>

Definiert den Namen des Tabs

<meta charset="UTF-8">

Definiert die Zeichencodierung der Seite, siehe charset.org

<meta name="viewport" content="width=device-width, initial-scale=1.0">

Definiert die Größe der Seite
width=device-width: Breite der Seite = Gerätbreite
initial-scale=1.0: Größe auf 100% Zoom

<link rel="icon" type="images/favicon" href="images/favicon.ico"

Das kleine Icon im Tab definieren mit 16x16 Pixel oder 32x32 Pixel, Größe kann festgelegt werden, muss aber quadratisch sein

Strukturelemente in <body>

<header>

Kopfzeile der Seite

<main>

Hauptsächlicher Inhalt der Seite

<footer>

Fußzeile der Seite

<nav>

Navigationsleiste definieren

<section>

Thematischer Abschnitt

<article>

Inhaltlich geschlossener Abschnitt, z.B. Blogposts oder Artikel

<div>

Division, Containerelement ohne Bedeutung
Hat keinen festen Platz in der Hirarchie

<aside>

Container für Zusatzinhalte, häufig seitlich auf der Website

Überschriften

<h1>

<h2>

<h3>

<h4>

<h5>
<h6>

Unterteilt Texte in Paragraphe

Paragraph 2

Zeilenumbruch innerhalb
eines Textes

Horizontale Linie zwischen Elementen

Listen

Unsortierte Liste

  • <ul> (unordered list) startet eine unsortierte Liste
  • <li> (list item) enthält einzelne Listeneinträge

Sortierte Liste

  1. <ol> (oredered list) startet eine sortierte Liste
  2. <li> (list item) enthält einzelne Listeneinträge

Beschreibungsliste

<dt> (description term) Gruppe von Begriffen (z.B. Früchte)
<dd> (description) Beschreibungen, Elemente (z.B. Apfel, Birne, ...)
Gemüse
Karotte

Links

<a href="#">Linkname</a>

Beispiel Interner Link

Beispiel Sprung innerhalb Seite zu Element mit der ID "headinhalt"

Attribut "target"
Beispielseite in gleichem Tab geöffnet (default)
Beispielseite in neuem Tab/Window geöffnet

<img>

Bild einbinden
<img src="pfad zum Bild" alt="Beschreibung des Bildes" width="Breite"/>

Attribute

lang="de"

Legt die Sprache innerhalb des Elements fest

id="eindeutiger Name"

Eindeutiger, frei wählbarer Bezeichner für ein Element

class="eindeutiger Name für Gruppe"

Frei wählbarer Bezeichner für eine Gruppe von Elementen

Formattierung mit HTML

<strong>

Text mit Informationen, die besonders wichtig sind!

Text fettgedruckt darstellen mit <b> wird inzwischen eigentlich nicht mehr verwendet

<em> (emphasis)

Text mit Informationen, die hervorgehoben werden sollen

Text kursiv darstellen mit <i> wird inzwischen eigentlich nicht mehr verwendet

Text unterstreichen

Text unterstreichen wollen wir eigentlich nicht, weil Links unterstrichen sind
